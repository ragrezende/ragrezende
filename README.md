Minha experiência na advocacia orienta os problemas que quero resolver com tecnologia: organizar informações, reduzir tarefas repetitivas e facilitar a preparação do trabalho jurídico.

## Projeto principal

- **[Doc Fracionado](https://ragrezende.github.io/doc-fracionado/):** divide PDFs para o peticionamento eletrônico, direto no navegador. Os arquivos não saem do computador, e cada limite de tribunal traz a fonte e a data da verificação. Código aberto, versão 0.1. [Código](https://github.com/ragrezende/doc-fracionado).

Os outros projetos e o estado real de cada um estão no [site](https://ragrezende.github.io/portfolio-website/).

## Como trabalho

Parto de problemas da rotina do escritório e busco soluções pequenas que também possam ajudar outros advogados. Utilizo desenvolvimento assistido por IA, com revisão e testes. Ferramentas de organização apoiam o trabalho profissional; não substituem a análise jurídica. Demonstrações usam dados fictícios; não publico informações de clientes.
